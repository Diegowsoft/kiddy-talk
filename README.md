# Kiddy Talk - Website Educativo para Crianças

Um website completo e interativo para ensinar inglês para crianças de forma divertida e educativa.

## 🎯 Sobre o Projeto

O Kiddy Talk é uma plataforma educativa desenvolvida especificamente para crianças de 4 a 12 anos aprenderem inglês através de jogos, lições interativas e conversações com personagens amigáveis.

## 🌟 Funcionalidades Principais

### 🏠 Home Page
- Design atrativo e colorido
- Apresentação dos personagens (Teddy Bear, Little Emma, Wise Turtle)
- Navegação intuitiva para todos os módulos
- Seção de benefícios e características

### 📚 Módulo de Inglês Básico
- **6 Lições Interativas:**
  - Cores (Colors)
  - Números (Numbers)
  - Animais (Animals)
  - Família (Family)
  - Comida (Food)
  - Cumprimentos (Greetings)
- Sistema de progresso visual
- Exercícios práticos com feedback
- Vocabulário com áudio simulado

### 💬 Módulo de Conversação
- **3 Personagens Interativos:**
  - Teddy Bear (Nível Iniciante)
  - Little Emma (Nível Intermediário)
  - Wise Turtle (Nível Avançado)
- Chat em tempo real simulado
- Respostas rápidas
- Sistema de pontuação
- Tópicos variados de conversação

### 🎮 Jogos Educativos
- **Jogo da Memória:** Encontre pares de palavras em inglês e português
- **Conecte as Palavras:** Conecte palavras em inglês com suas traduções
- **Quiz Divertido:** Responda perguntas sobre vocabulário
- Sistema de conquistas
- Leaderboard com melhores pontuações
- Dicas e ajudas disponíveis

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível
- **CSS3:** Estilos customizados com variáveis CSS
- **JavaScript:** Interatividade e lógica dos jogos
- **Tailwind CSS:** Framework CSS para design responsivo
- **Google Fonts:** Tipografia Fredoka (amigável para crianças)
- **LocalStorage:** Persistência de progresso e conquistas

## 📱 Responsividade

O website é totalmente responsivo e funciona perfeitamente em:
- 💻 Desktop (1200px+)
- 📱 Tablet (768px - 1199px)
- 📱 Mobile (320px - 767px)

## 🚀 Como Usar

1. **Abrir o Website:**
   - Abra o arquivo `index.html` em qualquer navegador moderno
   - Ou hospede os arquivos em um servidor web

2. **Navegação:**
   - Use o menu superior para navegar entre as seções
   - Clique nos botões para acessar diferentes módulos

3. **Módulo de Inglês:**
   - Escolha uma lição para começar
   - Complete os exercícios em sequência
   - Acompanhe seu progresso na barra superior

4. **Conversação:**
   - Selecione um personagem
   - Digite mensagens em inglês
   - Use as respostas rápidas para facilitar

5. **Jogos:**
   - Escolha um jogo baseado no nível de dificuldade
   - Complete os desafios para ganhar pontos
   - Desbloqueie conquistas jogando

## 🔧 Personalização

O website pode ser facilmente personalizado:
- **Cores:** Modifique as variáveis CSS em `styles.css`
- **Conteúdo:** Adicione novas lições em `english-module.js`
- **Jogos:** Implemente novos jogos em `game.js`
- **Personagens:** Adicione novos personagens em `conversation-module.js`

## 📊 Métricas de Sucesso

- **Engajamento:** Tempo gasto em cada módulo
- **Progresso:** Lições completadas
- **Retenção:** Retorno ao website
- **Conquistas:** Objetivos alcançados
