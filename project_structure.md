# Estrutura do Projeto Kiddy Talk Website

## Páginas Principais
1. **index.html** - Home page (página inicial)
2. **english-module.html** - Módulo de Inglês Básico
3. **conversation-module.html** - Módulo de Conversação
4. **game.html** - Jogo Educativo Interativo

## Estrutura de Pastas
```
kiddy-talk-website/
├── index.html
├── english-module.html
├── conversation-module.html
├── game.html
├── css/
│   └── styles.css
├── js/
│   ├── main.js
│   └── game.js
├── images/
│   └── (imagens do projeto)
└── assets/
    └── (recursos adicionais)
```

## Design System
- **Cores principais:**
  - Azul: #2EBBC0 (header/footer)
  - Amarelo: #FED700 (hero section)
  - Laranja: #FF6835 (módulo inglês)
  - Verde: #4CAF50 (jogos)
  - Rosa claro: #FF99FA22 (background)

- **Tipografia:**
  - Fonte principal: 'Fredoka' (Google Fonts)
  - Estilo amigável para crianças

- **Framework:**
  - Tailwind CSS (via CDN)
  - Responsivo mobile-first

## Funcionalidades por Página

### Home Page (index.html)
- Header com navegação
- Hero section com personagens
- Cards dos módulos
- Footer

### Módulo de Inglês (english-module.html)
- Lições básicas de vocabulário
- Exercícios interativos
- Progresso visual
- Áudio para pronúncia

### Módulo de Conversação (conversation-module.html)
- Diálogos interativos
- Personagens animados
- Simulação de conversas
- Feedback em tempo real

### Jogo Educativo (game.html)
- Jogo de memória com palavras
- Sistema de pontuação
- Níveis de dificuldade
- Animações e efeitos sonoros
