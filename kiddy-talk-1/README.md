# Kiddy Talk

Kiddy Talk é uma escola de inglês dedicada a oferecer cursos de alta qualidade para alunos de todas as idades. Este projeto é um site que apresenta informações sobre a escola, os cursos oferecidos, e como entrar em contato.

## Estrutura do Projeto

O projeto é organizado da seguinte forma:

```
kiddy-talk
├── src
│   ├── assets
│   │   ├── css
│   │   │   └── styles.css
│   │   └── js
│   │       └── main.js
│   ├── pages
│   │   ├── index.html
│   │   ├── cursos.html
│   │   ├── sobre.html
│   │   └── contato.html
├── .gitignore
└── README.md
```

## Como Configurar

1. Clone o repositório:
   ```
   git clone <URL_DO_REPOSITORIO>
   ```

2. Navegue até o diretório do projeto:
   ```
   cd kiddy-talk
   ```

3. Abra o arquivo `index.html` em um navegador para visualizar o site.
